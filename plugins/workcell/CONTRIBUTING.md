# Contributing

Thanks for helping improve Workcell.

- Keep changes generic. Do not include customer data, credentials, internal project decisions, or proprietary source from a host repository.
- For workflow claims, include the host runtime and version, setup, exact steps, result, and known limitations.
- For scripts, add tests for failure paths and unsafe inputs, not only the happy path.
- Keep the default behavior conservative. Network, publishing, destructive cleanup, and production actions must remain opt-in and owner-controlled.
- Avoid claims that a task is autonomous, verified, or safe unless the relevant behavior has been exercised.
